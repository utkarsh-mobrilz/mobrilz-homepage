# Mobrilz Technologies - Modern Web & Mobile App Homepage

An ultra-modern, high-performance, and responsive enterprise homepage for **Mobrilz Technologies**. Designed and engineered with precision pairing Tailwind CSS, vanilla JavaScript animations, and custom canvas-driven kinetic graphics.

---

## 🌟 Key Features

- **Dynamic Interactive Navigation**: Sticky floating glassmorphism header with active section tracking, seamless navigation links, and modern mobile drawer.
- **Hero Section**: Photorealistic showcases, typography-driven value proposition, and interactive CTA triggers.
- **Quantum Molecular Starburst UI (`#expertise`)**: Custom HTML5 Canvas rendering a 4-armed organic nucleus with 32 asynchronous breathing satellite nodes that organically pulse and swell at independent rates.
- **Agile Architecture Blueprint (`#technologies`)**: Cybernetic dark canvas with seamless full-bleed convex arch transitions (`[border-radius:50%_/_...]`) and persistent background grid continuity without seams.
- **Why Choose Us Bento Grid (`#why-us`)**: Light-themed modern card architecture with subtle borders, enterprise value points, and balanced spacing.
- **Interactive Portfolio Carousel (`#projects`)**: Multi-device showcase (mobile apps & web applications) with filterable category pills.
- **Perspectives on Engineering & AI (`#blogs`)**: Editorial 3-card grid featuring snug image framing and an interactive, floating **"View Article ↗"** cursor follower.
- **Modern Minimalist Footer (`#contact` / `#footer`)**:
  - Elevated rising convex arch transition.
  - `#FAFAFA` bold typography across all navigation columns (Company, Services, Industries, Resources).
  - Clean office address, working hours, and direct contact line.
  - Compact 3×2 social media grid.
  - Signature giant scroll-driven brand watermark logo.

---

## 🚀 Design Versions

1. **Design A (`index.html` & `design-a.html`)**: The primary production layout featuring dark midnight cybernetic accents, kinetic starburst canvas, convex section arches, and high-contrast editorial insights.
2. **Design B (`design-b.html`)**: Alternate exploration featuring minimalist light-card bento layouts.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**: Zero heavy framework dependencies, ultra-fast load times.
- **Tailwind CSS**: Modern utility-first styling with responsive breakpoints.
- **HTML5 Canvas 2D API**: 60fps kinetic motion and particle systems.
- **Lucide Icons**: Crisp, lightweight vector iconography.
- **Google Fonts**: Plus Jakarta Sans & Space Grotesk.

---

## 💻 Local Development

To run the site locally:

```bash
# Python built-in HTTP server
python -m http.server 3000

# Open in browser
open http://localhost:3000/
```
